# Codex Speed

独立的 macOS 悬浮球，以动态仪表显示 Codex 的生成速率（`token / s`）。拖动浮球可移动位置。右键可以调整设置、查看会话或退出。

## 打开应用

需要 macOS 14 或更新版本。下载压缩包后，解压并打开「Codex Speed」。[下载正式版](https://github.com/yqstart/codex-speed/releases/latest)

也可以用 Swift 工具链在项目目录构建，然后在访达中打开生成的 `dist/Codex Speed.app`。

```sh
./scripts/build-app.sh
```

## 悬浮球设置

右键菜单中的「悬浮球大小」可在 84 到 176 点之间调节。「表盘样式」可切换「动态仪表」和「简洁读数」。「配色」默认跟随 macOS 当前外观，也可固定为浅色或深色。调整会立即生效并保存在本机。

右键菜单中的「自动获取更新」默认关闭。开启后，应用会立即查询 GitHub 正式版，并在以后每次启动和运行期间每隔 6 小时查询。发现兼容的新版本后会下载并校验更新包，可从右键菜单选择「在访达中显示」并自行安装。

供自动更新的 GitHub 正式版标签使用 `v0.2.0` 或 `0.2.0` 这类格式。上传应用压缩包时使用 `Codex-Speed-0.2.0-arm64.zip`、`Codex-Speed-0.2.0-x86_64.zip` 或 `Codex-Speed-0.2.0-universal.zip`，以便应用按当前运行架构选择。更新包使用 GitHub 提供的 SHA-256 摘要校验。

## 读数

悬浮球读取本机 Codex 会话日志的模型、事件时间和输出用量，并用本地索引显示会话名。单会话时，球心显示速度。并行时，主球突出显示最近活跃或手动固定的会话，小球分别显示其他会话的速度。悬停在球上可查看会话标题，点击小球可将该会话固定到主球。超过四个会话时，点击「+N」查看全部会话。

右键菜单中的「会话」子菜单可查看各会话的模型和读数。已固定时，选择「取消固定」可恢复跟随桌面端最近活跃的会话。固定会话暂停后，主球临时跟随其他活跃会话，固定会话再次活跃时回到主球。

空闲时显示「待机」，有会话但暂无读数时显示「等待读数」。生成过程中，速度根据同一会话、同一模型的近期请求估算。Codex 写入本次用量后，会显示该次请求的平均速度。悬浮球遵循 macOS 的「减少动态效果」设置。

悬浮球与从日志取数的思路参考 [Agent Speed](https://github.com/zoefix/agent-speed/blob/bbe690a233c9ec4c9bac1e6793b065af9ab04905/spec/METRICS.md)。
