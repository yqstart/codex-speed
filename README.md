# Codex Speed

独立的 macOS 悬浮球，显示当前 Codex 会话及其生成速率（`token / s`）。单屏时，悬浮球跟随前台 Codex 桌面端。连接多个显示器时，悬浮球显示在 Codex 窗口位于最前方的屏幕上，切换到另一块屏幕工作时也能继续看读数。拖动浮球可移动位置。右键可以调整设置、查看会话或退出。

## 打开应用

需要 macOS 14 或更新版本。下载压缩包后，解压并打开「Codex Speed」。[下载正式版](https://github.com/yqstart/codex-speed/releases/latest)

也可以用 Swift 工具链在项目目录构建，然后在访达中打开生成的 `dist/Codex Speed.app`。

```sh
./scripts/build-app.sh
```

## 悬浮球设置

右键菜单中的「悬浮球大小」可在 84 到 176 点之间调节。「表盘样式」可切换「动态仪表」和「简洁读数」。「配色」默认跟随 macOS 当前外观，也可固定为浅色或深色。调整会立即生效并保存在本机。

「动态仪表」用青绿标识当前会话，用金色标识手动固定的读数。光弧和外沿光点会随速率变化，切换会话时会亮起扩散光纹。等待读数时显示脉冲波形，待机时显示呼吸灯。

右键菜单中的「检查更新」可立即查询 GitHub 正式版。「自动获取更新」默认关闭，开启后会在启动时以及运行期间每隔 6 小时检查。发现兼容的新版本后，应用会下载并校验安装包。

下载完成后，选择「安装并重启」即可原地替换当前应用。新版启动失败时会恢复原应用。自动更新需要应用所在目录可写。若应用位于只读位置，请移到可写的「应用程序」文件夹后重试。

供自动更新的 GitHub 正式版标签使用 `v0.2.0` 或 `0.2.0` 这类格式。上传应用压缩包时使用 `Codex-Speed-0.2.0-arm64.zip`、`Codex-Speed-0.2.0-x86_64.zip` 或 `Codex-Speed-0.2.0-universal.zip`，以便应用按当前运行架构选择。旧版发布包使用 GitHub 提供的 SHA-256 摘要校验。

将同一版本的发布 ZIP 传给下面的命令，并将生成的 `Codex-Speed-update.json` 和 ZIP 一起上传到该版本的发布页。更新器可直接下载清单并校验安装包。

```sh
./scripts/write-update-manifest.sh dist/Codex-Speed-0.4.2-universal.zip > dist/Codex-Speed-update.json
```

## 读数

悬浮球读取本机 Codex 会话日志的模型、事件时间和输出用量，并用本地索引显示会话名。表盘中央显示会话标题和速率，外圈弧长随该速率变化。悬停可查看完整会话名。当前会话空闲时，表盘仍显示它的标题和「待机」。

macOS 通过已有的「屏幕录制」权限提供窗口标题。悬浮球用最前面的 Codex 窗口标题匹配本机会话索引。标题不可用或无法唯一匹配时，表盘以「最近活跃」标记回退读数。

表盘底部的「并行」显示其余活跃会话的数量。点击数量或打开右键菜单的「会话」，可查看这些会话的读数。选择一个活跃会话可暂时固定它的读数。切换到另一个可识别的 Codex 会话，或选择「取消固定」，会恢复显示当前会话。

会话已开始生成但暂无读数时显示「等待读数」。生成过程中，速度根据同一会话、同一模型的近期请求估算。活跃会话暂时没有新读数时，会继续显示该会话当前模型的上一次读数。Codex 写入本次用量后，会显示该次请求的平均速度。悬浮球遵循 macOS 的「减少动态效果」设置。

悬浮球与从日志取数的思路参考 [Agent Speed](https://github.com/zoefix/agent-speed/blob/bbe690a233c9ec4c9bac1e6793b065af9ab04905/spec/METRICS.md)。
