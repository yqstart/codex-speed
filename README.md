# Codex Speed

独立的 macOS 悬浮球，以动态仪表显示 Codex 的生成速率（词元/秒）。拖动浮球可移动位置。右键可以查看会话或退出。

## 打开应用

在 Finder 中打开生成的 `dist/Codex Speed.app`。需要 macOS 14 或更新版本及对应架构的构建产物。

悬浮球启动时使用 macOS 当前的浅色或深色外观，运行期间也会随系统切换。

有 Swift 工具链时，可以在项目目录构建。

```sh
./scripts/build-app.sh
```

## 读数

悬浮球读取本机 Codex 会话日志的模型、事件时间和输出用量，并用本地索引显示会话名。并行运行时，右键菜单列出打开菜单时各会话的模型和读数。点某一项可固定到该会话。选择「自动显示最近活跃」可恢复优先跟随桌面端的最近活跃会话。

空闲时显示「待机」，有会话但暂无读数时显示「等待读数」。`≈` 表示根据同一会话、同一模型的近期请求估算的速度。Codex 写入本次用量后，会显示该次请求的平均速度。悬浮球遵循 macOS 的「减少动态效果」设置。

悬浮球与从日志取数的思路参考 [Agent Speed](https://github.com/zoefix/agent-speed/blob/bbe690a233c9ec4c9bac1e6793b065af9ab04905/spec/METRICS.md)。
